Privacy policy

Last updated: 17 November 2026

Faceless Pipeline is a private tool operated by New Dawn Origins. It is used only by its owner, on the owner's own computer, with the owner's own YouTube channels.

What it accesses

When the owner signs in with Google, the tool uses the YouTube API to upload videos, set titles, descriptions and thumbnails, schedule publishing, and read analytics for the owner's own channels.

What it stores

The sign-in token is stored on the owner's own computer. Nothing is sent to or stored on any server run by us, and no data is collected from any other person.

Sharing

We do not sell, share or disclose any data to third parties. The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

This tool uses YouTube API Services, subject to the YouTube Terms of Service and the Google Privacy Policy.
